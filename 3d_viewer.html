⚠️ Native SOLIDWORKS files aren't supported

.sldprt and .sldasm use a proprietary binary format that requires SOLIDWORKS (or its COM API) to read. No open-source tool can open them without SW installed — this is a hard limitation of the format, not this viewer.

Fix: In SOLIDWORKS, open the file and choose
File → Save As → STEP AP214 (.step)
then drop the .step file here. It's lossless and opens instantly.
